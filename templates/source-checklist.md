# Company Analysis Source Checklist

## Required where available

- [ ] Company identity resolved: name, ticker, exchange, CIK.
- [ ] Latest 10-K / annual report.
- [ ] Latest 10-Q / interim report.
- [ ] Recent 8-K / major event filings.
- [ ] Latest earnings release.
- [ ] Latest investor presentation.
- [ ] Earnings call transcript or webcast notes.
- [ ] DEF 14A / proxy for compensation, ownership, governance.
- [ ] Price, market cap, enterprise value date.
- [ ] Peer group and industry classification.

## Useful extras

- [ ] Product pages / pricing pages.
- [ ] Customer case studies.
- [ ] Careers / hiring signals.
- [ ] Patent / technical signals.
- [ ] Regulatory / legal database checks.
- [ ] News timeline for last 6-12 months.
- [ ] Macro / commodity / rate data if relevant.
- [ ] Alternative data only if clearly labeled.

## Data provenance fields

For every collected document:

- Title
- URL
- Source type
- Publication date
- Filing date, if different
- Access date
- Notes on reliability / limitations
