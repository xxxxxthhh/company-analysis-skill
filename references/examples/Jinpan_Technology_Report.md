# Example Report: 金盘科技 (Jinpan Technology)

> Shows: Chinese A-share analysis, policy catalyst mapping, VIE-free structure, bilingual report format

## Structural Highlights

### China-Specific Framework Application

**Company type:** A-share listed Chinese manufacturer (not ADR, not VIE-structured)
- No VIE risk — direct equity ownership, simpler governance analysis
- Reporting under Chinese GAAP → need to note differences vs US GAAP / IFRS
- Policy catalyst: China's domestic manufacturing push, grid infrastructure investment

**Key analytical layers unique to Chinese industrials:**
1. Policy alignment: which government initiatives drive demand? (e.g., 新基建, 国产替代)
2. Competitive landscape: domestic vs foreign competitors, import substitution dynamics
3. Regional exposure: revenue by province, overseas expansion risks
4. State-owned vs private: management incentives differ significantly

### Bilingual Format Convention

```
# 金盘科技 (Jinpan Technology) 深度研究报告 / Deep Research Report

中文报告 / EN Report
```

Standard bilingual convention from AtypicalLifeClub:
- `markdownFiles.zh`: 中文完整报告 (e.g., `金盘科技_深度研究报告_20260204.md`)
- `markdownFiles.en`: English complete report (e.g., `Jinpan_Technology_Deep_Research_Report_2026-02.md`)
- Same chapter structure, same key data — not summary translations
- `?lang=zh|en` parameter on the static site

### Key Metrics for Chinese Industrials

| Metric | Availability | Note |
|--------|-------------|------|
| Revenue / segment | 🔍 | Annual report (年报) |
| Gross margin | 🔍 | Annual report |
| Capacity utilization | 🔍 | Earnings call / investor presentation |
| Government subsidies as % of profit | 🔍 | Annual report footnotes — critical for Chinese industrials |
| Receivables aging | 🔍 | Balance sheet footnotes — cash conversion quality signal |
